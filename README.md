# Marketing Assets - שומרי האדמה

CDN repository for marketing materials.

## Available Content

### Shomrei Ha'Adama Landing Page
`shomrei-haadama-landing/`

- `images/` - hero & section images (jako, collage, mockup)
- `testimonial-photos/` - 6 testimonial photos

## CDN Access (jsDelivr)

Replace `{path}` with the actual file path:

```
https://cdn.jsdelivr.net/gh/jakog-hub/marketing-assets@main/{path}
```

### Example:
```
https://cdn.jsdelivr.net/gh/jakog-hub/marketing-assets@main/shomrei-haadama-landing/images/jako.jpg
```

## GitHub Raw (Alternative)

```
https://raw.githubusercontent.com/jakog-hub/marketing-assets/main/{path}
```
